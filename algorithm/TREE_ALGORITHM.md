# 二叉树可视化（build + print）核心流程

> 代码文件：`tree_printer.go`

## 1. 功能概述

本算法实现两件事：

1. **从先序数组构建二叉树**：按 `根 -> 左 -> 右` 的顺序展开，`-2` 表示空节点（哨兵）。
2. **可视化打印二叉树**：按层自顶向下输出，带 `┌─┴─┐` 分支连线，方便肉眼核对树结构。

## 2. 核心流程总览

```
先序数组 arr
    │
    ▼
[Step 1] buildPreorder: 递归消费数组 → 构建 Node 树
    │
    ▼
[Step 2] 中序遍历 → 为每个节点分配横坐标 xs（保证左在左、右在右、父居中）
    │
    ▼
[Step 3] DFS 求最大深度 maxD → 确定画布行数 rows = (maxD+1)*2 - 1
    │
    ▼
[Step 4] 按层收集节点 → 在画布"节点行"填数字
    │
    ▼
[Step 5] 相邻两层之间画"连线行"（┌ ─ ┴ ┐）
    │
    ▼
[Step 6] 逐行输出画布
```

## 3. Step 1：先序构建（buildPreorder）

- **入参**：`arr []int`（先序展开，`-2` 表示空）、指针 `i` 记录消费位置。
- **逻辑**：
  1. 读取当前值 `v`，若越界或 `v == -2` 返回 `nil`。
  2. 否则创建节点 `{Val: v}`，递归构建 `Left`，再递归构建 `Right`。
- **注意**：`i` 必须传指针，保证整个递归共享同一消费游标。
- **结构定义**：

```go
type Node struct {
    Val         int
    Left, Right *Node
}
```

## 4. Step 2：中序遍历分配横坐标

- **目标**：让每个节点在画布上有唯一横坐标 `xs[n]`，并保证父节点落在左右子树坐标之间（天然居中）。
- **原理**：中序遍历顺序 = 树中所有节点在水平方向上的从左到右排列，因此递增计数器 `nextX` 赋值即可。
- **复杂度**：O(N)。

## 5. Step 3：确定画布尺寸

- DFS 求出最大深度 `maxD`（根深度为 0）。
- **列数**：`totalCols = 节点总数`（即 `nextX`），每列宽 `colW = 4`，总宽度 `width = totalCols * 4`。
- **行数**：`rows = (maxD+1)*2 - 1`（每层占 1 个节点行 + 1 个连线行，首尾无连线）。
- 初始化 `grid` 为 `rows × width` 的空字符画布。

## 6. Step 4：填充节点行

- BFS/DFS 按层收集节点到 `levelNodes[d]`。
- 对第 `d` 层每个节点：节点位置 `base = xs[n]*colW + 1`，用 `strconv.Itoa` 把数字写入画布（覆盖到第 2 行起即 `d*2` 行）。

## 7. Step 5：绘制连线行

- 对第 `d` 层的每个节点，在第 `d*2+1` 行画分支：
  - 有左孩子：在 `┌` 处落笔，向左孩子横坐标方向填充 `─`。
  - 有右孩子：向右孩子横坐标方向填充 `─`，末端以 `┐` 收尾。
  - 只要存在任一孩子，父节点正下方画 `┴`。

## 8. Step 6：输出

逐行 `fmt.Println` 画布，即得到如下效果：

```
                        10
        ┌───────────────┴───────────────┐
        0                               12
    ┌───┴───┐                       ┌───┴───┐
    1       11                      0       1
┌───┴───┐       ┌───┴───┐       ┌───┴───┐
15       11      3       4       1
```

## 9. 复杂度

| 指标 | 复杂度 |
| --- | --- |
| 构建 | O(N) 时间 / O(N) 栈空间 |
| 坐标分配 | O(N) |
| 打印 | O(N²) 最坏（画布宽高均为 O(N)） |
| 总空间 | O(N) 节点 + O(N²) 画布 |

## 10. 主要用法

```go
arr := []int{10, 0, 1, -2, -2, 11, -2, 1, 15, -2, -2, 11, -2, -2, 12, -2, 0, 3, -2, 4, -2, -2, 1, -2, -2}
i := 0
root := buildPreorder(arr, &i)
printTree(root)
```
