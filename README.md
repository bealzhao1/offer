# offer

算法练习与代码片段汇总。

## 目录结构

- `algorithm/` —— 各类算法实现（Go）
  - `binary_tree/` —— 二叉树相关
    - `binary_tree_build.go` —— 二叉树先序构建 + 可视化打印（带分支连线）
    - `traversal.go` —— 先序/中序/后序遍历（递归 + 栈两种实现）
    - `TREE_ALGORITHM.md` —— 二叉树可视化算法的核心流程文档
    - `TREE_TRAVERSAL.md` —— 二叉树三种遍历的核心流程文档
  - `graph/` —— 图相关（Go 库）
    - 表示/遍历/拓扑/环检测/最短路/MST/并查集/二分图/连通性/网络流
    - `example/main.go` —— 演示入口
    - `GRAPH_ALGORITHM.md` —— 图算法文档
